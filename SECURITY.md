# Security Policy

## Important

The wallet has not undergone an independent professional security audit.
Use small test amounts first. Do not store funds you cannot afford to lose.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's
private vulnerability reporting feature for this repository if it is enabled.
If private reporting is not available, contact the maintainers privately before
disclosing technical details publicly.

## User safety

- Never share your WIF/private key or wallet password.
- Verify the receiving address, amount, fee, and change output before signing.
- Use an Index Server you operate or trust.
- Treat on-chain OP_RETURN memos as public and irreversible.
- Keep encrypted backups in a separate secure location.
