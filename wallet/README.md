# nextBTC Wallet V0.5.84

A self-contained browser wallet for the nextBTC network.

- Open `nextBTC_Wallet_V0.5.84_CertificateCheck.html` in a modern browser.
- Configure your own compatible Index Server in Settings.
- The initial server URL is intentionally a reserved placeholder:
  `https://your-index-server.example:8777`.
- Use **Trust certificate** to open the Index Server's `/certificate-check`
  page. After the browser allows the HTTPS connection, return to the wallet
  and refresh the home page.
- The Index Server implementation is not included in this Wallet-only release.
- See the root README and `docs/` for API requirements and security notes.
